## 1. 프로젝트 개요

본 프로젝트는 **Amazon Movies & TV 리뷰 데이터**를 활용하여, 사용자의 리뷰 텍스트에서 **감정(Emotion)**을 추출하고 이를 기반으로 영화를 추천하는 **감정 기반 추천 시스템**입니다.

### 핵심 아이디어
- 기존 협업 필터링(Collaborative Filtering)이 평점만을 활용하는 한계를 극복
- 리뷰 텍스트에 담긴 **감정 정보**(즐거움, 슬픔, 분노, 긴장, 설렘, 편안함 등)를 추가 피처로 활용
- **NCF(Neural Collaborative Filtering)** 모델에 감정, 장르, 제목 임베딩을 결합한 하이브리드 추천

### 기술 스택
| 분류 | 기술 |
|------|------|
| 언어 | Python |
| 데이터 처리 | Pandas, NumPy |
| NLP | NLTK, TF-IDF, Hugging Face Transformers |
| 감정 분류 | DistilBERT (`bhadresh-savani/distilbert-base-uncased-emotion`) |
| 딥러닝 | TensorFlow / Keras |
| 시각화 | Matplotlib, Seaborn |
| 평가 | scikit-learn |

### 파일 구조
```
├── movies_chunk_code.ipynb        # 원본 데이터 파싱 (txt → CSV 청크 분할)
├── chunk_title_code.ipynb         # 메타데이터 매핑 (ASIN → 영화 제목)
├── fianl_data_save.ipynb          # 청크 병합 및 최종 데이터 저장
├── text_analysis.ipynb            # 텍스트 전처리 + 감정 라벨링 + EDA
├── deep_code_class_after.ipynb    # NCF 모델링 + 과적합 해결 + 성능 평가
└── README.md
```

## 2. 데이터 수집 및 전처리

### 2.1 원본 데이터
- **데이터 출처**: Amazon Movies & TV 리뷰 데이터셋
- **원본 형식**: 텍스트 파일 (`movies.txt`), key-value 쌍 형태
- **원본 규모**: 약 **791만 건**의 리뷰

### 2.2 데이터 파싱 (`movies_chunk_code.ipynb`)
원본 텍스트 파일을 파싱하여 구조화된 CSV로 변환하였습니다.
- 10만 건 단위로 청크 분할 저장 (메모리 효율성 확보)
- 총 **80개의 청크 파일** 생성
- 파싱 필드: `product/productId`, `review/userId`, `review/score`, `review/summary`, `review/text` 등

### 2.3 메타데이터 매핑 (`chunk_title_code.ipynb`)
`meta_Movies_and_TV.json` 파일에서 ASIN(상품 ID)과 영화 제목을 매핑하여 `movie_title` 컬럼을 추가하였습니다.

### 2.4 데이터 병합 및 정제 (`fianl_data_save.ipynb`)
- 80개 청크 파일을 하나의 데이터프레임으로 병합
- 불필요한 컬럼 제거: `review/userId`, `review/profileName`, `review/helpfulness`, `review/time`
- 결측치(NaN) 제거
- **최종 데이터**: 약 **126만 건**, 5개 컬럼 (`item_id`, `rating`, `summary`, `text`, `title`)

### 2.5 텍스트 전처리 (`text_analysis.ipynb`)
리뷰 텍스트에 대해 다음의 NLP 전처리를 수행하였습니다:

1. **토큰화 (Tokenization)**: NLTK `word_tokenize`
2. **소문자 변환 (Lowercasing)**
3. **불용어 제거 (Stopword Removal)**: 영어 불용어 + 비알파벳 문자 제거
4. **표제어 추출 (Lemmatization)**: WordNet 기반
5. **TF-IDF 벡터화**: 전처리된 텍스트를 수치 벡터로 변환
   - 결과 행렬 크기: `(224,961 × 182,038)`

## 3. 감정 라벨링 및 편향 해결

### 3.1 감정 분류 모델
사전학습된 **DistilBERT 감정 분류 모델**(`bhadresh-savani/distilbert-base-uncased-emotion`)을 활용하여 리뷰 텍스트에 감정 라벨을 부여하였습니다.

- 배치 추론(batch_size=32)으로 처리 속도 최적화
- 512 토큰 초과 시 자동 truncation 적용

### 3.2 감정 매핑 체계

| 영어 라벨 | 한글 감정 | 설명 |
|-----------|-----------|------|
| joy | 즐거움 | 기쁨, 만족 |
| sadness | 슬픔 | 슬픔, 아쉬움 |
| anger | 분노 | 분노, 불만 |
| fear | 긴장 | 긴장, 공포 |
| surprise | 설렘 | 놀라움, 기대 |
| love | 편안함 | 사랑, 안정 |

이후 모델링 단계에서 세분화된 9가지 감정 카테고리로 확장:
**즐거움, 슬픔, 분노, 긴장, 설렘, 편안함, 감동, 감탄, 유머러스**

### 3.3 감정 편향 문제
- 평점 5점 리뷰가 전체의 상당 부분을 차지하여 **긍정 감정(즐거움, 감탄)**에 편중
- 이를 해결하기 위해 모델 훈련 시 **클래스 가중치(class weights)** 적용
- 부정 클래스에 더 높은 가중치를 부여하여 감정 분포의 불균형을 보정

## 4. 최종 전처리

NCF 모델에 입력하기 위해 다음과 같은 최종 전처리를 수행하였습니다:

### 4.1 피처 엔지니어링
- **사용자/아이템 ID 인코딩**: 원본 ID → 정수 인코딩 (`user_id_encoded`, `item_id_encoded`)
- **장르 원-핫 인코딩**: 26개 장르 (Action, Comedy, Drama, Sci-Fi 등)
- **감정 피처**: `refined_emotion_*`, `dominant_emotion_*` 컬럼 (9개 감정 카테고리)
- **제목 임베딩**: `title_emb_*` 컬럼으로 영화 제목의 벡터 표현
- **연도 정보**: 영화 출시 연도

### 4.2 데이터 분할
- **훈련**: 156,139건 (70%)
- **검증**: 33,458건 (15%)
- **테스트**: 33,459건 (15%)
- **타겟 변수**: 평점 기반 이진 분류 (긍정/부정)
  - 긍정(1): 높은 평점 / 부정(0): 낮은 평점
  - 긍정 비율 48.02%, 부정 비율 51.98%

### 4.3 결측치 처리
- 제목 임베딩: 중위값(median)으로 대체
- 감정 피처: 0으로 대체
- 연도: 중위값으로 대체

## 5. 모델링: NCF

### 5.1 모델 아키텍처
**NCF(Neural Collaborative Filtering)** 기반의 하이브리드 추천 모델을 구현하였습니다.

```
입력 레이어
├── User Embedding (user_id → 임베딩 벡터)
├── Item Embedding (item_id → 임베딩 벡터)
├── Genre Features (26차원 원-핫)
├── Emotion Features (refined + dominant 감정)
└── Title Embedding (제목 벡터)
        │
        ▼
   Concatenate (모든 피처 결합)
        │
        ▼
   Dense(256) + BatchNorm + Dropout
        │
        ▼
   Dense(128) + BatchNorm + Dropout
        │
        ▼
   Dense(64) + BatchNorm + Dropout
        │
        ▼
   Dense(1, sigmoid) → 추천 확률
```

### 5.2 주요 구성 요소
- **임베딩 크기**: 64
- **은닉층**: [256, 128, 64]
- **활성화 함수**: ReLU
- **출력층**: Sigmoid (이진 분류)
- **옵티마이저**: Adam (lr=0.001)
- **손실 함수**: Binary Crossentropy
- **총 파라미터**: 약 840만 개

## 6. 과적합 해결 과정

초기 모델에서 훈련 정확도(88~90%)와 검증 정확도(68%) 사이의 큰 격차가 발생하여, 과적합을 해결하기 위한 점진적 개선을 수행하였습니다.

### 6.1 1단계: 기본 정규화 적용
- **Dropout** (0.3) 추가
- **Early Stopping** (patience=3, val_loss 기준)
- **ReduceLROnPlateau** (학습률 자동 감소)
- 결과: Epoch 4에서 조기 종료, val_auc 0.76

### 6.2 2단계: 안전한 과적합 방지 (`SafeDataProcessor`)
- **BatchNormalization** 각 Dense 레이어 뒤에 추가
- **L2 정규화** (가중치 규제)
- **엄격한 데이터 분할**: 사용자 기반 분리 (데이터 누수 방지)
  - 훈련/검증/테스트에 동일 사용자가 포함되지 않도록 분리
- 학습률을 0.0001로 낮춤
- 결측치 처리에 중위값 사용 (평균 대신)

### 6.3 3단계: 점진적 성능 개선 (`IncrementalDataProcessor`)
- **RobustScaler** 적용 (이상치에 강건한 스케일링)
- **체계적 하이퍼파라미터 튜닝**: 3가지 설정 비교
- **클래스 가중치** 적용 (불균형 데이터 대응)
- **최적 임계값 탐색**: 0.1 ~ 0.9 범위에서 F1 기준 최적값 도출

### 과적합 해결 전후 비교

| 지표 | 기존 모델 | 개선 모델 | 개선율 |
|------|-----------|-----------|--------|
| Accuracy | 0.6821 | **0.7134** | +4.6% |
| Precision | 0.6523 | **0.8412** | +29.0% |
| Recall | 0.7240 | **0.7415** | +2.4% |
| F1 Score | 0.6863 | **0.7882** | +14.8% |
| AUC-ROC | 0.7541 | 0.7487 | -0.7% |

> 전체 평균 개선율: **+10.02%**, Precision에서 가장 큰 향상(+29.0%)

## 8. 프로젝트 의의 및 배운점

### 프로젝트 의의
1. **감정 정보의 추천 시스템 적용**: 단순 평점 기반이 아닌, 리뷰 텍스트에서 추출한 감정을 활용한 추천은 사용자의 미묘한 선호도를 반영할 수 있음을 확인
2. **하이브리드 접근**: 협업 필터링(사용자-아이템 상호작용)과 콘텐츠 기반 필터링(장르, 감정, 제목)을 NCF 프레임워크 안에서 통합
3. **대규모 데이터 처리 경험**: 약 791만 건의 원본 데이터를 청크 단위로 효율적으로 처리하는 파이프라인 구축

### 배운점
1. **과적합의 체계적 해결**: Dropout, BatchNorm, L2 정규화, EarlyStopping, 사용자 기반 데이터 분할 등을 조합하여 과적합을 점진적으로 해결하는 방법론 습득
2. **감정 분류의 한계 인식**: 사전학습 모델의 감정 분류가 리뷰 도메인에서 완벽하지 않으며, 도메인 특화 파인튜닝의 필요성 확인
3. **평가 지표의 다양성**: 분류 지표(Accuracy, F1)와 추천 시스템 고유 지표(NDCG, MRR, Hit Rate)를 함께 활용하여 모델을 다각도로 평가하는 중요성 학습
4. **클래스 불균형 대응**: 감정 분포의 편향이 모델 성능에 미치는 영향을 직접 경험하고, 클래스 가중치 등의 기법으로 해결

## 9. 추후 보완사항

1. **감정 분류 모델 파인튜닝**: 영화 리뷰 도메인에 특화된 감정 분류 모델을 직접 학습하여 분류 정확도 향상
2. **부정 감정 재현율 개선**: 슬픔, 분노, 긴장 등 부정 감정에 대한 추천 성능이 상대적으로 낮으므로, 해당 감정에 대한 추가 데이터 수집 또는 오버샘플링 기법 적용
3. **시퀀스 기반 모델 도입**: 사용자의 시간순 시청 이력을 반영하는 RNN, Transformer 기반 추천 모델 적용
4. **Cold Start 문제 해결**: 신규 사용자나 리뷰가 부족한 영화에 대한 추천 전략 보완
5. **실시간 추천 서비스**: Flask/FastAPI 기반의 API 서버 구축 및 배포
6. **다국어 지원**: 현재 영어 리뷰에 한정되어 있으므로, 다국어 감정 분류 모델 도입으로 확장 가능
7. **A/B 테스트**: 감정 기반 추천과 기존 평점 기반 추천의 실사용자 대상 비교 실험
8. **설명 가능한 추천**: 왜 해당 영화가 추천되었는지 감정 기반 설명을 제공하는 기능 추가
